# 独自方策の経済計画改善（2026-09-20）

## 完了条件と評価順序

前サイクルの残作業は、(1) 主力との差の収支分解、(2) 経済計画の実装・比較、(3) 未知seed・別相手での再評価と昇格判断。Public提出は含めない。勝てなかった候補を主力へ昇格させず、その判断にも比較結果を残す。

## 収支分解

`outputs/strategy-cycle/economic-gap-v3.json` はseed 138000–138007・両seat、16対戦を両者の視点で計32回計測したもの。各試合で初期資金＋実売上−全購入費−雇用費−土地費と最終報酬の一致を確認。

主力の費用は牛8頭版より12,522.81多く、そのうち追加雇用費は5,668。主力は費用を抑えるより、生産構成を増やして収入を伸ばしている。数量差と平均約定単価差も対称分解してJSONに保存した。片側で生産しない商品の単価効果は識別できないため、全額を商品構成・数量差に割り当てた。この分解は会計的説明であり、価格への因果効果の推定ではない。

## 実装した比較候補

- 牛・羊を半数ずつ配置し、小麦・イチゴ・メロンを区画ごとに固定分散。
- 土地購入後にも既設家畜の配置予定を維持。
- 25/50/75区画、8/10/12 hands、8/12頭、土地購入用の資金余裕を比較。
- 継続生産作物の肥料利用、給餌用小麦のまとめ取り。
- 牛乳40単位の保有と終盤売却、牛4頭への縮小。
- 既存 `planner_cows8` と主力 `candidate` を比較対照として残す。

smokeでは分散生産版が有望。肥料利用版は初期資金と作業の競合があり、診断seed 138100で家畜5頭が逃亡したため、この実装を採用しない。50区画への拡張は生産を増やすが雇用費も増えるため、cashだけで採用しない。

## 再現・監査

各実験の `manifest.json` に方策・相手・seed範囲・worker数・ソースSHA-256を保存している。`scripts/evaluate_independent.py` へ同じ引数を渡し、新しい出力先で再現できる。

最終監査コマンド：

```sh
.venv/bin/python scripts/audit_economy_v4.py --output outputs/strategy-cycle/economy-v4-audit.json
```

全対戦の欠落・重複・先後・719ステップ完了・有限な報酬・集計値を照合する。各段階のseed分離、ソースの一致、候補選択規則、paired信頼区間、ZIPの内容とhash、両版の収支再計算も検査する。

別相手の評価にはローカルの方策群を使う。新たな強い公開参加者のコードを入手して評価したものではなく、Public順位の改善を保証しない。
