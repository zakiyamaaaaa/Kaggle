# OMW observed front-run v1

One More Wheat原版を変更せず、公開観測だけから相手の大量売却周期を学習し、
こちらの予定売却を1〜2 turn先行させるローカル実験。

## 安全条件

- 対象は `MILK / WOOL / STRAWBERRY / MELON / EGG` のみ。
- 市場価格4以上でのみ動作する。
- 相手の同一商品について最低3回の売却イベントが必要。
- 直近2周期が中央値±2 turn以内の場合だけ予測する。
- 相手の予測売却量、こちらの実在庫、24 turn以内の予定売却量、100 unitsの最小値だけ売る。
- 前倒し分は将来の親SELLから差し引き、総売却予定量を増やさない。
- One More Wheat原版は `references/` 配下で凍結し、この実験からimportする。

## 注意

これはローカル実験用であり、そのままではKaggle提出用の単一`main.py`ではない。
採用時に親コードをinlineし、同一挙動を確認してbundleする。
